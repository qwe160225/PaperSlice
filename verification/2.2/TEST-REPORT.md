# QPDF 2.2 预览与高清翻页验证报告

日期：2026-11-10（北京时间）。基于用户提供的 2.1.0 源码修改。

## 修复与新增

- 移除“输入页码与已高亮页相同就不跳转”的判断；重复搜索也会滚回目标页。
- 缩略图列表改用 RecyclerView / GridLayoutManager 定位目标页，避免全列表刷新打断定位。
- 在键盘、窗口边距和尺寸改变期间保留搜索定位；用户主动拖动或选择其他页后解除定位。测试曾发现收起模拟键盘后末页离开视口，修复后通过同一断言。
- 搜索仍停留在缩略图预览；双击进入对应页高清。高清从 PDF 重新渲染，不是简单放大缩略图。
- ViewPager2 横向滑动切换相邻页面，并提供上一页/下一页按钮。支持首末页边界及 Android 返回键；退出高清后定位到当前页的缩略图。
- 单后台线程；缩略图缓存 12 MiB，高清缓存 48 MiB。高清仅保留当前与相邻两页；单张长边不超过 3072 像素且不超过 400 万像素。旧的待执行任务会被新目标替换；正在执行的单页渲染完成后切换任务。
- 包名、开发签名和 QPDF 提取核心保持一致；版本号 2.2.0 / 22，可覆盖安装 2.0 / 2.1。

## 验证限制

本轮未连接 Android 真机或完整模拟器。Robolectric 交互测试使用替身渲染器，不验证系统 PdfRenderer 真实画面、手机触摸手感、设备文件提供器、加密/修复文件的实际渲染、长时间运行或 1 GB 文件在手机上的速度。HD 渲染参数与生产接线已编译及静态检查，不能把上述测试等同于真机验收。

未重跑原生大文件基准和 JNI 集成测试；未改提取核心，2.0 历史结果保存在 verification/2.0。2.1 历史报告保存在 verification/2.1。图片缓存预算不代表系统 PDF 解码器或整个进程峰值内存。复杂 PDF 单页渲染仍可能较慢。

建议真机验收：打开原先大 PDF，搜索 1、400、末页；滚动离开后再搜同页；收起/弹出键盘；双击进入高清，左右连续翻页；返回缩略图确认位置；最后回到主界面提取原先页段。
